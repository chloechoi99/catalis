Metric Definitions

Net Worth: Month-end cash + total portfolio value.
Emergency Coverage: Month-end cash ÷ monthly living expenses.
Savings Rate: (Cash increase + contribution) ÷ income for the month.
Monthly Return: Market gain only — new contributions are excluded to avoid distortion.
Cash Interest: Uses actual interest if entered; otherwise estimated as Opening Cash × APR ÷ 12.
Data Storage: Click Link File to bind a JSON file inside your Google Drive sync folder. Every save writes to that file automatically. Without linking, data lives in browser localStorage — use Backup JSON periodically.
